# Computer Vision Portfolio

## Overview

This repository contains a collection of computer vision projects developed during my Master's studies in Mechatronics. The projects focus on image processing, object detection, augmented reality, and depth estimation using modern computer vision techniques.

## Included Projects

### Edge Detection

* Sobel Filter
* Canny Edge Detector

### Augmented Reality using ARUCO Markers

* Marker detection
* Pose estimation
* Perspective transformation
* Virtual object overlay

### Object Detection and Depth Estimation

* YOLO-based object detection
* Distance estimation of detected objects
* Real-time image processing
